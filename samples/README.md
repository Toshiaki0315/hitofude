# 読み込みを試すファイル

**同じ内容を 5 つの形で出したもの。**「ファイル」→「読み込む…」に入れて、
どの経路で何が残り、何が落ちるかを並べて見るために置いてある。

作り直すときは次を実行する（中身を変えたら入れ替える）。

```bash
uv run python scripts/make_import_samples.py
```

## 入っているもの

どれも中身は同じで、**見出し・段落・箇条書き・罫線付きの表・角丸の箱と
矢印**が 1 枚に入っている。

| ファイル                | 通る道                          | 実測    |
| ----------------------- | ------------------------------- | ------- |
| `会議メモ.pdf`          | 文字入りの PDF（そのまま取り出す）| 0.0 秒 |
| `会議メモ-スキャン.pdf` | 絵だけの PDF（読み取りに回る）  | 0.5 秒  |
| `会議メモ.png`          | 画像（読み取りに回る）          | 0.5 秒  |
| `会議メモ.jpg`          | 同上（写真に近い圧縮）          | 0.5 秒  |
| `会議メモ.pptx`         | PowerPoint（構造のまま読む）    | 0.0 秒  |

## 何が残り、何が落ちるか（実測）

| | 表 | 図形 |
| --- | --- | --- |
| 文字入り PDF | 罫線は消え、文字が 1 行に並ぶ | 箱の中の字だけ |
| スキャン PDF・画像 | **列ごとに縦に読まれる** | 箱の中の字（矢印は `→` で残ることがある）|
| PowerPoint | **表のまま**（罫線付き） | 箇条書きになる |

**表は構造を持っている PowerPoint だけが表として戻る。** PDF と画像は
文字の並びになり、スキャンでは列ごとに縦読みになる — これは
[ADR-0027](../docs/adr/0027-ocr.md) の「やらないこと」に書いた割り切りで、
読み取りが返す並びをそのまま使っているため。

## 読み取りの相手を変えて比べる

設定（`Cmd+,`）→「アシスタント」→「文字の読み取り」で
`macOS（デフォルト）` と `ローカルLLM` を切り替えられる。**同じファイルで
比べられる**ようにこの一式がある。
