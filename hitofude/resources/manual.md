# Hitofude の使い方

ようこそ。このノート自体が Markdown で書かれているので、**書き方の見本**にもなります。
不要になったら `Cmd+Delete` でゴミ箱へ入れてください。

## このアプリの考え方

編集画面とプレビュー画面が分かれていません。書きながら装飾が反映されます。

記号（`**` や `#`）は**カーソルがその要素の外にあるとき隠れます**。中に入れると
現れて、そのまま直せます。この行の *斜体* や `コード` にカーソルを合わせてみてください。

ノートは**素の `.md` ファイル**として保存されます。独自形式は使いません。
`~/Documents/HitofudeNotes` を Finder で開けば、そのまま他のアプリでも読めます。

## 書き方

本文の上のボタンからも付けられます（次の節）。

### 文字の装飾

これは **強調**、これは *斜体*、これは ~~取り消し線~~、これは ::ハイライト::、
そしてこれは `インラインコード` です。

日本語でも**前後に空白を入れずに**装飾できます。「**強調**」のように括弧に
隣接しても効きます。

### 箇条書きとタスク

- 項目を書いて Enter を押すと、次の行にも `- ` が付きます
- Tab で字下げ、Shift+Tab で戻せます
    - 入れ子にした項目
- 空の項目で Enter を 2 回押すと、ふつうの段落に戻ります

1. 番号付きの箇条書き
2. 番号は自動で 1 つ進みます
3. 途中の番号は振り直しません（差分を小さく保つため）

- [ ] まだ終わっていない項目
- [x] 終わった項目

**チェックの印はクリックで切り替わります**（`Cmd+Shift+T` でも）。
本文の上を押しても切り替わりません。

### 引用とコード

> 引用は左に縦線が付きます。
> 行末で Enter を押すと引用が続きます。

```python
def hello() -> str:
    """コードブロックの中では装飾が一切効きません。"""
    return "**これは強調になりません**"
```

コードの中で Enter を押すと、**前の行の字下げがそのまま続きます**。

言語を書くと**予約語や文字列に色が付きます**（画面でも、書き出しでも）。
言語を書かなければ色は付きません。とても長いコード（200 行より上）は、
打つのが重くならないよう色を付けません。

### 表

表は縦線を揃えると読みやすくなります。行から離れると**自動で揃い、罫線が付きます**。
手で揃えたいときは `Cmd+Shift+L` を押してください。

| 記法   | 書き方       | 結果     |
| ------ | ------------ | -------- |
| 強調   | `**文字**`   | **文字** |
| 斜体   | `*文字*`     | *文字*   |
| コード | `` `文字` `` | `文字`   |

表の中にカーソルを入れると罫線が消えて `|` が現れます。そのまま編集できます。

**幅に収まらない表は、罫線を出さずに生の Markdown で表示します。** 折り返した
行に罫線を引くと、列がずれて嘘の表になるためです。1 行に入るのは **71 桁**
（日本語で 35 文字ぶん）まで。本文の幅は決まっているので、ウィンドウを広げても
増えません。セルを短くするか、**書き出し（HTML / PDF）で見てください**。
書き出しでは幅に関係なく、きちんとした表になります。

### 画像

**画像はそのまま貼り付けられます。** スクリーンショットを撮って `Cmd+V`、
または画像ファイルをウィンドウへドラッグしてください。`attachments/` に
保存され、本文には `![](attachments/…)` が入ります。

**その場に絵が出ます。** カーソルを入れても絵は消えず、行の高さも変わりません。
パスを直したいときは `Cmd+/` で生の Markdown に戻せます。

大きい画像は本文の幅に収めて表示します（元のファイルは縮みません）。

本文から画像を消しても、ファイルは `attachments/` に残ります。溜まってきたら
**「ファイル」→「使っていない添付を片づける…」**を押してください。どのノート
からも使われていない添付を数えて、**確認してからゴミ箱へ移します**（消しません。
30 日は戻せます）。ゴミ箱の中のノートや雛形からの参照も数えるので、
うっかり使用中の画像が片づけられることはありません。

### リンク

[Markdown の仕様](https://spec.commonmark.org/) のように書きます。
`Cmd+K` で選択した文字をリンクにできます。URL をコピーした状態で文字を選んで
`Cmd+V` すると、リンクとして貼り付きます。

**`Cmd+クリック` で既定のブラウザが開きます。** 開くのは `http` / `https` /
`mailto` だけです（本文は手で編集できるので、それ以外は開きません）。

`Cmd` を押すと、**押せるものの上でカーソルが手の形になります**（リンク・タグ・
`[[ノート名]]`）。マウスを置いたまま `Cmd` を押しても変わります。開けないもの
（`javascript:` など）の上では変わりません。

### ノート同士を繋ぐ

`[[会議メモ]]` と書くと、その名前のノートへのリンクになります。
`[[` と `]]` は隠れて、名前だけがリンク色で出ます。

**`Cmd+クリック` でそのノートへ飛びます。** まだ無ければ、その名前で
**新しいノートを作って開きます**（見出しも入った状態です）。書きながら
「あとで書くノート」を先に指しておけます。

大文字小文字と前後の空白は気にしなくて大丈夫です。`[[名前|表示名]]` の
書き方には対応していないので、そう書くとただの文字のまま残ります。

**指されている側には、本文の下に帯が出ます。** 「▸ バックリンク 3」を
押すと、指しているノートとその行が並びます。押せばそのノートへ飛べます。
`Cmd+4` でも開閉できます。**指されていないノートでは帯ごと出ません。**

繋がりの元はファイルの中身なので、他のアプリで `.md` を開けば
`[[会議メモ]]` という文字がそのまま見えます。

### タグ

本文のどこにでも `#タグ` と書けます。`/` で階層にできます。
左のサイドバーにツリーとして出ます。

`#` の**直前は行頭か空白**である必要があります。URL の `#anchor` を
タグと誤認しないためです。

**タグを `Cmd+クリック` すると、そのタグで一覧が絞り込まれます。**

`#` を打つと**既にあるタグが候補として出ます**。矢印で選んで、そのまま
打ち続けるか、クリックで決まります。`Esc` で閉じられます。

### Qiita 向けの書き方

Qiita に貼るときの記法にも対応しています。まず囲みです。

:::note info
これが `:::note info` の囲みです。**強調**も箇条書きも中で使えます。
:::

:::note warn
`warn` は黄色。注意を促すとき。
:::

:::note alert
`alert` は赤。危険なとき。
:::

書き方はこうです。種類を省くと `info` になります。

    :::note info
    お知らせです。
    :::

`:::` の行は画面では消えていて、**カーソルを入れると現れます**。
囲みであることは左の色付きの縦線で分かります。

**綴りを間違えると灰色の線になり、`:::note warm` の行も消えません。**
`info` の青で出してしまうと、間違えたことに気づけないためです。
`:::note warn さらに何か` のように語を 2 つ以上書いた場合は、囲みになりません。

コードブロックには**ファイル名**を付けられます。画面ではコードの上に、
書き出しでは見出しとして出ます。

```js:index.js
const greeting = "書き出すとファイル名が見出しとして出ます";
```

**脚注**も書けます[^1]。書き出すと本文のいちばん下にまとまります。

[^1]: これが脚注の中身です。`[^1]: ` で始まる行が定義になります。

**図**も描けます。` ```mermaid ` で囲むと、HTML に書き出したときに図になります。

    ```mermaid
    graph TD
      A[開始] --> B[終了]
    ```

画面とPDF ではコードのまま出ます（図にするのはブラウザの機能を借りているためです）。
図のあるノートを HTML に書き出すと、描画用の部品を中に取り込むぶん
ファイルが 3.4MB ほど大きくなります。**ネットが無くても図は出ます。**

**数式**も書けます。`$` で囲むと文中に、`$$` で囲むと独立した式になります。

    アインシュタインの式 $E = mc^2$ は有名です。

    $$
    x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
    $$

画面では等幅で表示され（複数行の `$$` はコードと同じ背景になります）、
**HTML に書き出すと組版されます**。PDF は書いた
ままの `$E = mc^2$` で出ます（PDF の描画側が数式を解さないためで、
間違った式を出さないようにこうしています）。

`$` は値段にも使うので、**`価格は $100 と $200 です。` は数式になりません**。
記号のすぐ内側に空白があるもの、数字が隣り合うもの、日本語を含むものは
数式として扱いません。

**これらは Markdown の標準ではありません。** 他のアプリで開くとそのままの
文字に見えますが、書いた内容は何も失われません。

## 書式ツールバー

本文の上に並んでいるボタンで、太字・斜体・打ち消し・コード・マーカー・
見出し・箇条書き・番号付き・チェックボックス・引用・リンクを付けられます。
ショートカットを覚えていなくても押せます。

- **囲む系（太字など）は、先に文字を選んでから押します。** 選ばずに押すと
  記号だけが置かれ、その間にカーソルが入ります
- **行の書式（箇条書き・番号付き・引用）は、選んだ行すべてに効きます。**
  行の途中までしか選んでいなくても、その行は丸ごと対象です
- もう一度押すと外れます。`Cmd+Z` は 1 回で元に戻ります
- 「見出し」は押すたびに 段落 → 大見出し → 中見出し → 小見出し → 段落 と
  一周します。もっと深い見出しは `Cmd+Shift+↓` で付けられます
- 邪魔なときは `Cmd+3` で隠せます。次に開いたときも隠れたままです

## 資料を読み込む

**「ファイル」→「読み込む…」で PDF と PowerPoint をノートにできます。**
もらった講演資料や配布資料を Markdown にして、自分のメモを書き足す使い方を
想定しています。

- 題名は**ファイル名**です（`講演資料.pptx` → `講演資料`）
- **元のファイルは触りません。** 読むだけで、移動も複製もしません
- **スライド 1 枚が `##` の 1 節**になります

**ざっくり読み取って、手で直す前提です。** 元のレイアウト（配色・段組み・
位置）は戻りません。戻るのは中身だけです。

PowerPoint からは次のものを拾います。

| 元                     | 取り込んだ結果                      |
| ---------------------- | ----------------------------------- |
| スライドのタイトル     | `##`                                |
| 行頭記号の無い短い段落 | `###`                               |
| 箇条書き（階層も）     | `- `（字下げ付き）                  |
| 表                     | Markdown の表                       |
| 画像                   | `attachments/` に保存して `![](…)` |
| 太字・等幅の文字       | `**強調**` と `` `コード` ``        |
| 発表者ノート           | 引用（`> `）                        |

**PowerPoint は平文と箇条書きを区別しません。** どちらも同じ形で保存される
ためで、こちらでは「`。`『`！`』などで終わる段落は本文、それ以外は箇条書き」と
見なしています。外れることがあるので、そこは直してください。

PDF は文字だけを取り出します。「見出し」「箇条書き」という情報が残って
いないので、`##` や `- ` は完全には復元できません。文の折り返しは繋ぎ直し、
ページ番号は落とします。**PDF からは画像を取り込みません。**

読めなかったときは知らせるだけで、**空のノートは作りません**（画像を並べた
だけの資料や、保護されたファイル）。

## テンプレートと今日のノート

**`Cmd+Shift+N` で雛形から作れます。** 「議事録」「日報」「日次」の 3 つが
最初から入っています。選ぶとすぐ書き始められる場所にカーソルが来ます。

**`Cmd+T` で今日のノートが開きます。** 無ければ `2026-08-14` のような
日付の題名で作ります。**同じ日に何度押しても同じノートが開きます**（書いた
ものが 2 つに割れません）。雛形の「日次」がそのまま使われます。

雛形は `HitofudeNotes/templates/` にある**ただの `.md`** です。Finder で
足せばそのまま候補に出ますし、中身を直せば次から反映されます。
**雛形はノートの一覧には出ません**（書くためのもので、読むものではないため）。

雛形の中では次の印が使えます。

| 印           | 入るもの                                 |
| ------------ | ---------------------------------------- |
| `{{date}}`   | 日付。`{{date:%Y年%m月%d日}}` で書式指定 |
| `{{time}}`   | 時刻。同じく書式を指定できます           |
| `{{title}}`  | 付ける題名                               |
| `{{cursor}}` | 作った直後にカーソルを置く場所           |

知らない印はそのまま残ります（消えたほうが困るためです）。

## Raw（生の Markdown を見る）

ツールバーの右端の **Raw** を押すと、隠れていた記号（`**` や `#`、表の `|`、
`:::` など）が全部見えます。**そのまま直せます。** 飾り（罫線・囲みの縦線・
チェックの印）も消えるので、Markdown そのものを触りたいときに使います。

もう一度押すと元に戻ります。`Cmd+/` でも同じです。**書いた内容は何も
変わりません。** 見せ方が変わるだけです。

**先頭の `id` などは Raw でも出ません。** アプリの管理情報で、書く人が
触るものではないためです（書き出しにも出ません）。

## 書き出し

「ファイル」メニューから 4 つの形式で書き出せます。書き出しても**元のノートは
変わりません**。

| 形式       | キー          | 中身                                       |
| ---------- | ------------- | ------------------------------------------ |
| Markdown   | `Cmd+Shift+M` | 書いたそのまま。記号も残ります             |
| HTML       | `Cmd+Shift+E` | 1 ファイルで完結。**画像も埋め込まれます** |
| PDF        | （メニュー）  | A4。表の罫線とコードの背景も付きます       |
| PowerPoint | （メニュー）  | `#` が表紙、`##` ごとに 1 枚               |

- HTML と PDF には**チェックボックス（☐ / ☑）・`:::note` の囲み・
  コードのファイル名・脚注**もそのまま出ます
- HTML は画像を中に取り込むので、**別の場所へ移しても絵が消えません**
- どの形式でも front matter（`id` や `modified`）は出ません。アプリの
  管理情報で、読む人には意味がないためです
- PDF だけは**引用の縦線が出ません**（PDF の描画側の制限です）。
  HTML には出ます

### PowerPoint で書き出す

**ざっくり作って PowerPoint で整える**前提です。配色や位置の細かい調整は
向こうでしてください。

- `#`（大見出し）が**表紙**、その下の段落が副題になります
- `##`（中見出し）ごとに**スライド 1 枚**
- 箇条書き・小見出し・表・コードはそのまま入ります
- **画像は本文の右側**に置かれます（本文は左半分に寄ります）
- `>` の引用は**発表者ノート**になります（スライドには出ません）

雛形の「PowerPoint下書き」（`Cmd+Shift+N`）に、表紙と各ページの形が
入っています。**書き出したものは読み戻せます**（「読み込む…」）。

## 印刷

`Cmd+P` で印刷ダイアログが開きます。刷るのは画面と同じ組み方（A4・余白 18mm）で、
書き出した PDF と同じものが出ます。

**ダイアログの左下の「PDF」から「PDF として保存」も選べます。** 以前は
`Cmd+P` が PDF 書き出しでしたが、macOS では印刷が慣習なので譲りました。
書き出しのほうは「ファイル」→「PDF で書き出す…」に残っています。

## ブラウザで確認・HTML をコピー

- **「ファイル」→「ブラウザで確認」（`Cmd+Shift+B`）** — 書き出さずに既定の
  ブラウザで開きます。**画面では図にならない Mermaid・数式・コードの色が
  ここで見られます。** 一時ファイルへ書くので、保管フォルダは汚れません
- **「ファイル」→「HTML をコピー」** — 書式付きでコピーします。メールや
  チャットにそのまま貼れます。画像も一緒に入ります

## 覚えておくと安心なこと

- **保存は自動です。** 入力が止まって 0.8 秒後、ノートを切り替えたとき、
  アプリを閉じたときに書き込まれます。まだ書けていない間は
  ウィンドウのタイトルに `•` が付き、**書けたら右下に保存した時刻**が出ます
  （打ち始めると消えます）
- **今入っているモード**（Raw / フォーカス / タイプライタ）が右下に出ます。
  何も入っていなければ何も出ません。ツールバーを隠していると（`Cmd+3`）
  Raw かどうかはここでしか分かりません
- **文字数と行数**が右下に出ます。装飾の記号（`**` など）と front matter、
  改行そのものは数に入りません
- **次に開くと、前回書いていたノートがそのまま開きます**
- **`Cmd+[` で来た道を戻れます。** 押した回数だけ前のノートへ遡ります
- **外部エディタと併用できます。** 別のアプリで書き換えると自動で読み直します。
  両方で同時に編集した場合は、どちらを残すか尋ねます
- **消えたファイルは `.trash` にあります。** 30 日で自動削除されます
  （日数は環境設定で変えられます）。左の「ゴミ箱」を開き、一覧を右クリックして
  **「元に戻す」**で戻せます
- **今すぐ消すこともできます。** ゴミ箱の一覧を右クリックして
  **「完全に削除…」**（1 件）、左の「ゴミ箱」を右クリックして
  **「ゴミ箱を空にする…」**（全部）。どちらも件数か名前を見せて確認します。
  **戻せません**
