# Hitofude の使い方

ようこそ。このノート自体が Markdown で書かれているので、**書き方の見本**にもなります。
不要になったら `Cmd+Delete` でゴミ箱へ入れてください。

**このノートは、いま入っているアプリに合わせて置き直せます。**
「ヘルプ」→「使い方のノートを置き直す」で最新版が出ます（今あるノートは
消えず、別のファイルとして置かれます）。

## このアプリの考え方

編集画面とプレビュー画面が分かれていません。書きながら装飾が反映されます。

記号（`**` や `#`）は**カーソルがその要素の外にあるとき隠れます**。中に入れると
現れて、そのまま直せます。この行の *斜体* や `コード` にカーソルを合わせてみてください。

ノートは**素の `.md` ファイル**として保存されます。独自形式は使いません。
`~/Documents/HitofudeNotes` を Finder で開けば、そのまま他のアプリでも読めます。

## 画面の見方

左から**サイドバー**・**ノートの一覧**・**本文**の 3 つに分かれています。
`Cmd+1` / `Cmd+2` でサイドバーと一覧を隠せます（本文だけにできます）。

| サイドバー | 出るもの                                   |
| ---------- | ------------------------------------------ |
| すべて     | ゴミ箱以外のノート全部                     |
| お気に入り | ピン留めしたノート                         |
| ゴミ箱     | 捨てたノート（30 日で自動削除）            |
| タグ       | 本文に書いた `#タグ`（階層のまま並びます） |

一覧の左上の `⇅` で並び順（更新順・作成順・名前順）、右上の `＋` で新規。
**右クリック**からは次のことができます。

| 項目           | すること                                       |
| -------------- | ---------------------------------------------- |
| ピン留め       | お気に入りに入れる（一覧の先頭に出ます）       |
| 名前を変更…   | 見出しを書き換える（ファイル名も一緒に変わる） |
| 複製           | 写しを作って開く（雛形として使い回すとき）     |
| リンクをコピー | `[[名前]]` の形でコピーする                    |
| Finder で表示  | 実物の `.md` を選んだ状態で開く                |
| ゴミ箱へ移動   | 捨てる（30 日は戻せます）                      |

画面の右下には、**今のモード**（Raw / フォーカス / タイプライタ）・
**最後に保存した時刻**・**文字数と行数**が出ます。

## 書き方

本文の上のボタンからも付けられます（次の節）。

### 文字の装飾

これは **強調**、これは *斜体*、これは ~~取り消し線~~、これは ::ハイライト::、
そしてこれは `インラインコード` です。

日本語でも**前後に空白を入れずに**装飾できます。「**強調**」のように括弧に
隣接しても効きます。

### 箇条書きとタスク

- 項目を書いて Enter を押すと、次の行にも `- ` が付きます
- Tab で字下げ、Shift+Tab で戻せます
    - 入れ子にした項目
- 空の項目で Enter を 2 回押すと、ふつうの段落に戻ります

1. 番号付きの箇条書き
2. 番号は自動で 1 つ進みます
3. 途中の番号は振り直しません（差分を小さく保つため）

- [ ] まだ終わっていない項目
- [x] 終わった項目

**チェックの印はクリックで切り替わります**（`Cmd+Shift+T` でも）。
本文の上を押しても切り替わりません。

### 引用とコード

> 引用は左に縦線が付きます。
> 行末で Enter を押すと引用が続きます。

```python
def hello() -> str:
    """コードブロックの中では装飾が一切効きません。"""
    return "**これは強調になりません**"
```

コードの中で Enter を押すと、**前の行の字下げがそのまま続きます**。

言語を書くと**予約語や文字列に色が付きます**（画面でも、書き出しでも）。
言語を書かなければ色は付きません。とても長いコード（200 行より上）は、
打つのが重くならないよう色を付けません。

言語名は打ちかけると**候補が出ます**（`\`\`\`py` まで打つと python などが
並びます）。矢印キーで選んで Enter か Tab で確定、Esc で閉じます。

言語名は [Pygments の一覧](https://pygments.org/languages/)（約 600 言語）が
そのまま使えます。`python` `javascript` `html` `css` `json` `yaml` `bash`
`sql` `go` `rust` `java` `c` `cpp` `ruby` `php` `diff` など。`py` `js` `ts`
`sh` のような**別名も効きます**。知らない言語名を書いてもエラーには
ならず、色なしでそのまま表示されます。

### 表

表は縦線を揃えると読みやすくなります。行から離れると**自動で揃い、罫線が付きます**。
手で揃えたいときは `Cmd+Shift+L` を押してください。

| 記法   | 書き方       | 結果     |
| ------ | ------------ | -------- |
| 強調   | `**文字**`   | **文字** |
| 斜体   | `*文字*`     | *文字*   |
| コード | `` `文字` `` | `文字`   |

表の中にカーソルを入れると罫線が消えて `|` が現れます。そのまま編集できます。

**幅に収まらない表は、セルの中で折り返して表示します。** 1 行に入るのは
標準の本文幅で **69 桁**（日本語で 34 文字ぶん）。超えたぶんはセル内で
折り返すので表のまま読めます。桁数を増やしたいときは、設定（Cmd+,）の
「本文の幅」を「広め」か「最大」にしてください。
折り返した表でも、カーソルを入れた行だけは生の `|` に戻ってそのまま
編集できます。書き出し（HTML / PDF）では幅に関係なく、きちんとした表に
なります。

### 見出しの折りたたみ

見出し行の**左の余白に小さな三角**が出ます。クリックすると、その見出しの
節（次の同じ深さの見出しの手前まで）が畳まれます。もう一度クリックすると
開きます。`#` の見出しは、配下の `##` ごと畳みます。

畳んでも本文は変わりません（保存される内容はそのまま）。隠れた行に検索や
ジャンプで飛ぶと自動で開きます。折りたたみの状態はノートを開き直すと
リセットされます。

### 画像

**画像はそのまま貼り付けられます。** スクリーンショットを撮って `Cmd+V`、
または画像ファイルをウィンドウへドラッグしてください。`attachments/` に
保存され、本文には `![](attachments/…)` が入ります。

**その場に絵が出ます。** カーソルを入れても絵は消えず、行の高さも変わりません。
パスを直したいときは `Cmd+/` で生の Markdown に戻せます。

大きい画像は本文の幅に収めて表示します（元のファイルは縮みません）。

本文から画像を消しても、ファイルは `attachments/` に残ります。溜まってきたら
**「ファイル」→「使っていない添付を片づける…」**を押してください。どのノート
からも使われていない添付を数えて、**確認してからゴミ箱へ移します**（消しません。
30 日は戻せます）。ゴミ箱の中のノートや雛形からの参照も数えるので、
うっかり使用中の画像が片づけられることはありません。

### リンク

[Markdown の仕様](https://spec.commonmark.org/) のように書きます。
`Cmd+K` で選択した文字をリンクにできます。URL をコピーした状態で文字を選んで
`Cmd+V` すると、リンクとして貼り付きます。

**`Cmd+クリック` で既定のブラウザが開きます。** 開くのは `http` / `https` /
`mailto` だけです（本文は手で編集できるので、それ以外は開きません）。

`Cmd` を押すと、**押せるものの上でカーソルが手の形になります**（リンク・タグ・
`[[ノート名]]`）。マウスを置いたまま `Cmd` を押しても変わります。開けないもの
（`javascript:` など）の上では変わりません。

### ノート同士を繋ぐ

`[[会議メモ]]` と書くと、その名前のノートへのリンクになります。
`[[` と `]]` は隠れて、名前だけがリンク色で出ます。

**`Cmd+クリック` でそのノートへ飛びます。** まだ無ければ、その名前で
**新しいノートを作って開きます**（見出しも入った状態です）。書きながら
「あとで書くノート」を先に指しておけます。

**`[[` と打つと候補が出ます。** 既にあるノートの題名から選べます（打つほど
絞られます）。選ぶと `]]` まで入ります。今開いているノートは出ません
（自分へのリンクは意味がないため）。

大文字小文字と前後の空白は気にしなくて大丈夫です。`[[名前|表示名]]` の
書き方には対応していないので、そう書くとただの文字のまま残ります。

**指されている側には、本文の下に帯が出ます。** 「▸ バックリンク 3」を
押すと、指しているノートとその行が並びます。押せばそのノートへ飛べます。
`Cmd+4` でも開閉できます。**指されていないノートでは帯ごと出ません。**

繋がりの元はファイルの中身なので、他のアプリで `.md` を開けば
`[[会議メモ]]` という文字がそのまま見えます。

### タグ

本文のどこにでも `#タグ` と書けます。`/` で階層にできます。
左のサイドバーにツリーとして出ます。

`#` の**直前は行頭か空白**である必要があります。URL の `#anchor` を
タグと誤認しないためです。

**タグを `Cmd+クリック` すると、そのタグで一覧が絞り込まれます。**

`#` を打つと**既にあるタグが候補として出ます**。矢印で選んで、そのまま
打ち続けるか、クリックで決まります。`Esc` で閉じられます。

### Qiita 向けの書き方

Qiita に貼るときの記法にも対応しています。まず囲みです。

:::note info
これが `:::note info` の囲みです。**強調**も箇条書きも中で使えます。
:::

:::note warn
`warn` は黄色。注意を促すとき。
:::

:::note alert
`alert` は赤。危険なとき。
:::

書き方はこうです。種類を省くと `info` になります。

    :::note info
    お知らせです。
    :::

`:::` の行は画面では消えていて、**カーソルを入れると現れます**。
囲みであることは左の色付きの縦線で分かります。

**綴りを間違えると灰色の線になり、`:::note warm` の行も消えません。**
`info` の青で出してしまうと、間違えたことに気づけないためです。
`:::note warn さらに何か` のように語を 2 つ以上書いた場合は、囲みになりません。

コードブロックには**ファイル名**を付けられます。画面ではコードの上に、
書き出しでは見出しとして出ます。

```js:index.js
const greeting = "書き出すとファイル名が見出しとして出ます";
```

**脚注**も書けます[^1]。書き出すと本文のいちばん下にまとまります。

[^1]: これが脚注の中身です。`[^1]: ` で始まる行が定義になります。

**図**も描けます。` ```mermaid ` で囲むと図になります。

    ```mermaid
    graph TD
      A[開始] --> B[終了]
    ```

**画面では、カーソルが外にある間 図で表示されます**（最初の 1 枚だけ
描くのに 1 秒ほどかかります）。カーソルを入れると生のコードに戻って
そのまま直せます。書けない図は生のまま出します。

PDF ではコードのまま出ます。図のあるノートを HTML に書き出すと、
描画用の部品を中に取り込むぶんファイルが 3.4MB ほど大きくなります。
**どちらもネットが無くても図は出ます。**

**数式**も書けます。`$` で囲むと文中に、`$$` で囲むと独立した式になります。

    アインシュタインの式 $E = mc^2$ は有名です。

    $$
    x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
    $$

`$$` は**行頭から**書いてください（上の例の字下げは記法をそのまま
見せるためのもので、字下げしたまま書くとコードブロック扱いになります）。

`$$` の式は、**カーソルが外にある間は画面でも組版されて表示されます**。
カーソルを式に入れると生の LaTeX に戻ってそのまま直せます。書けない式
（閉じ忘れ・文法の間違い）は組版せず生のまま出します。文中の `$ 〜 $` は
等幅表示のままです。

**HTML に書き出すと文中の式も組版されます**。PDF は書いた
ままの `$E = mc^2$` で出ます（PDF の描画側が数式を解さないためで、
間違った式を出さないようにこうしています）。

`$` は値段にも使うので、**`価格は $100 と $200 です。` は数式になりません**。
記号のすぐ内側に空白があるもの、数字が隣り合うもの、日本語を含むものは
数式として扱いません。

**これらは Markdown の標準ではありません。** 他のアプリで開くとそのままの
文字に見えますが、書いた内容は何も失われません。

## 書式ツールバー

本文の上に並んでいるボタンで、太字・斜体・打ち消し・コード・マーカー・
見出し・箇条書き・番号付き・チェックボックス・引用・リンクを付けられます。
ショートカットを覚えていなくても押せます。

- **囲む系（太字など）は、先に文字を選んでから押します。** 選ばずに押すと
  記号だけが置かれ、その間にカーソルが入ります
- **行の書式（箇条書き・番号付き・引用）は、選んだ行すべてに効きます。**
  行の途中までしか選んでいなくても、その行は丸ごと対象です
- もう一度押すと外れます。`Cmd+Z` は 1 回で元に戻ります
- 「見出し」は押すたびに 段落 → 大見出し → 中見出し → 小見出し → 段落 と
  一周します。もっと深い見出しは `Cmd+Ctrl+↓` で付けられます
- 邪魔なときは `Cmd+3` で隠せます。次に開いたときも隠れたままです

## 探す

探し方は 4 つあります。**目的で使い分けます。**

| 探すもの               | キー          | 出るもの                     |
| ---------------------- | ------------- | ---------------------------- |
| 題名（ノートを開く）   | `Cmd+O`       | 題名の候補                   |
| 本文（すべてのノート） | `Cmd+Shift+F` | 抜粋つきの候補               |
| このノートの中         | `Cmd+F`       | 下に検索バー（置換もできる） |
| このノートの見出し     | `Cmd+R`       | 見出しの一覧                 |

### 題名から開く（`Cmd+O`）

**続けて打たなくても当たります。** 「かいぎ」と打てば「今週の会議メモ」が
出ます（文字が順番に含まれていれば拾います）。頭から続けて一致するもの、
区切りの直後から始まるものが上に来ます。大文字小文字は気にしません。

### 本文から探す（`Cmd+Shift+F`）

**すべてのノートの本文**を探し、見つかった箇所の抜粋が出ます。
選ぶと**そのノートを開いて、一致した行まで飛びます**。

`**予算**について` のように記号を挟んで書いていても、`予算について` で
見つかります（記号を外してから照合しています）。

**タグで絞れます。** `#仕事 予算` と書くと、`#仕事` の付いたノートの中から
`予算` を探します。書く順は問いません（`予算 #仕事` でも同じ）。

- タグを 2 つ以上書くと、**全部付いているノート**だけが出ます
- `#仕事` だけ書くと、そのタグのノートが並びます
- **`#仕事` で `#仕事/会議` も出ます**（親を指定すると子も含みます）

**期間でも絞れます。** `after:2026-08-01` でその日以降、`before:2026-08-31` で
その日以前に**更新した**ノートだけになります。**どちらもその日を含みます。**
タグと混ぜても書けます（`#仕事 after:2026-08-01 予算`）。

日付は `2026-08-01` の形（ゼロ詰め）で書きます。読めない書き方
（`after:きのう`）は絞り込みにせず、**そのまま探す言葉**として扱います。
そのときは検索欄の下に**書き方の案内**が出るので、打ち間違いに気づけます。

### このノートの中を探す（`Cmd+F`）

本文の下に検索バーが出ます。`Cmd+G` で次、`Cmd+Shift+G` で前へ。
**置換もここでします**（1 件ずつ、またはすべて）。「大文字小文字を区別」も
選べます。`Esc` で閉じます。

### 見出しへ飛ぶ（`Cmd+R`）

長いノートの中を移動する用です。見出しが階層のまま並び、選ぶとその場所へ
飛びます。

**出したままにもできます。** `Cmd+5`、本文の上の**アウトラインのボタン**（Raw の隣）、左下の歯車、表示メニューのどれからでも開けます。本文の右に見出しの一覧が
出ます。押せばその場所へ飛び、打てば中身も追いつきます。次に開いたときも
出したままです。`Cmd+R` は「飛んだら閉じる」道具なので、用途で使い分けて
ください。

### タグで絞る

左のサイドバーのタグを選ぶと、そのタグの付いたノートだけが一覧に出ます。
本文の `#タグ` を `Cmd+クリック` しても同じです。

## 資料を読み込む

**「ファイル」→「読み込む…」で PDF と PowerPoint をノートにできます。**
もらった講演資料や配布資料を Markdown にして、自分のメモを書き足す使い方を
想定しています。

手元の `.md` ファイルは、**ノートの一覧へドラッグ＆ドロップ**しても
取り込めます。コピーして追加するので、元のファイルは触りません。

- 題名は**ファイル名**です（`講演資料.pptx` → `講演資料`）
- **元のファイルは触りません。** 読むだけで、移動も複製もしません
- **スライド 1 枚が `##` の 1 節**になります

**ざっくり読み取って、手で直す前提です。** 元のレイアウト（配色・段組み・
位置）は戻りません。戻るのは中身だけです。

PowerPoint からは次のものを拾います。

| 元                     | 取り込んだ結果                      |
| ---------------------- | ----------------------------------- |
| スライドのタイトル     | `##`                                |
| 行頭記号の無い短い段落 | `###`                               |
| 箇条書き（階層も）     | `- `（字下げ付き）                  |
| 表                     | Markdown の表                       |
| 画像                   | `attachments/` に保存して `![](…)` |
| 太字・等幅の文字       | `**強調**` と `` `コード` ``        |
| 発表者ノート           | 引用（`> `）                        |

**PowerPoint は平文と箇条書きを区別しません。** どちらも同じ形で保存される
ためで、こちらでは「`。`『`！`』などで終わる段落は本文、それ以外は箇条書き」と
見なしています。外れることがあるので、そこは直してください。

PDF は文字だけを取り出します。「見出し」「箇条書き」という情報が残って
いないので、`##` や `- ` は完全には復元できません。文の折り返しは繋ぎ直し、
ページ番号は落とします。**PDF からは画像を取り込みません。**

読めなかったときは知らせるだけで、**空のノートは作りません**（画像を並べた
だけの資料や、保護されたファイル）。

## テンプレートと今日のノート

**`Cmd+Shift+N` で雛形から作れます。** 「議事録」「日報」「日次」の 3 つが
最初から入っています。選ぶとすぐ書き始められる場所にカーソルが来ます。

**`Cmd+T` で今日のノートが開きます。** 無ければ `2026-08-14` のような
日付の題名で作ります。**同じ日に何度押しても同じノートが開きます**（書いた
ものが 2 つに割れません）。雛形の「日次」がそのまま使われます。

**`Cmd+Shift+[` と `Cmd+Shift+]` で日付を辿れます。** 書いた日だけを飛び石で
移動します（書かなかった日は飛ばします）。**空のノートは作りません**ので、
端まで来たら「これより前の日のノートはありません」と出ます。

**書いたノートを雛形にできます。** 一覧でノートを右クリック →
「テンプレートに登録…」で名前を付けると、次から `Cmd+Shift+N` の候補に
出ます。見出しは自動で `{{title}}` に置き換わるので、この雛形から作った
ノートには新しい題名が入ります。同じ名前の雛形があるときは上書きするか
確認します。**要らなくなったテンプレートは**メニューの
「ファイル → テンプレートを削除…」から選んで消せます。

雛形は `HitofudeNotes/templates/` にある**ただの `.md`** です。Finder で
足せばそのまま候補に出ますし、中身を直せば次から反映されます。
**雛形はノートの一覧には出ません**（書くためのもので、読むものではないため）。

雛形の中では次の印が使えます。

| 印           | 入るもの                                 |
| ------------ | ---------------------------------------- |
| `{{date}}`   | 日付。`{{date:%Y年%m月%d日}}` で書式指定 |
| `{{time}}`   | 時刻。同じく書式を指定できます           |
| `{{title}}`  | 付ける題名                               |
| `{{cursor}}` | 作った直後にカーソルを置く場所           |

知らない印はそのまま残ります（消えたほうが困るためです）。

## Raw（生の Markdown を見る）

ツールバーの右端の **Raw** を押すと、隠れていた記号（`**` や `#`、表の `|`、
`:::` など）が全部見えます。**そのまま直せます。** 飾り（罫線・囲みの縦線・
チェックの印）も消えるので、Markdown そのものを触りたいときに使います。

もう一度押すと元に戻ります。`Cmd+/` でも同じです。**書いた内容は何も
変わりません。** 見せ方が変わるだけです。

**先頭の `id` などは Raw でも出ません。** アプリの管理情報で、書く人が
触るものではないためです（書き出しにも出ません）。

## 書き出し

「ファイル」メニューから 4 つの形式で書き出せます。書き出しても**元のノートは
変わりません**。

| 形式       | キー          | 中身                                   |
| ---------- | ------------- | -------------------------------------- |
| Markdown   | `Cmd+Shift+M` | 書いたそのまま。記号も残ります         |
| HTML       | `Cmd+Shift+E` | 1 ファイルで完結。画像も埋め込まれます |
| PDF        | （メニュー）  | A4。表の罫線とコードの背景も付きます   |
| PowerPoint | （メニュー）  | `#` が表紙、`##` ごとに 1 枚           |

**書き出すと、保存先が画面の下に出ます。** 右側に出る**「Finder で表示」**を
押すと、そのファイルを選んだ状態で Finder が開きます。知らせはしばらくすると
消えます（前に書き出したファイルを指したままにしないため）。

- HTML と PDF には**チェックボックス（☐ / ☑）・`:::note` の囲み・
  コードのファイル名・脚注**もそのまま出ます
- HTML は画像を中に取り込むので、**別の場所へ移しても絵が消えません**
- どの形式でも front matter（`id` や `modified`）は出ません。アプリの
  管理情報で、読む人には意味がないためです
- PDF だけは**引用の縦線が出ません**（PDF の描画側の制限です）。
  HTML には出ます

### PowerPoint で書き出す

**ざっくり作って PowerPoint で整える**前提です。配色や位置の細かい調整は
向こうでしてください。

- `#`（大見出し）が**表紙**、その下の段落が副題になります
- `##`（中見出し）ごとに**スライド 1 枚**
- 箇条書き・小見出し・表・コードはそのまま入ります
- **画像は本文の右側**に置かれます（本文は左半分に寄ります）
- `>` の引用は**発表者ノート**になります（スライドには出ません）

雛形の「PowerPoint下書き」（`Cmd+Shift+N`）に、表紙と各ページの形が
入っています。**書き出したものは読み戻せます**（「読み込む…」）。

## 印刷

`Cmd+P` で印刷ダイアログが開きます。刷るのは画面と同じ組み方（A4・余白 18mm）で、
書き出した PDF と同じものが出ます。

**ダイアログの左下の「PDF」から「PDF として保存」も選べます。** 以前は
`Cmd+P` が PDF 書き出しでしたが、macOS では印刷が慣習なので譲りました。
書き出しのほうは「ファイル」→「PDF で書き出す…」に残っています。

## ブラウザで確認・HTML をコピー

- **「ファイル」→「ブラウザで確認」（`Cmd+Shift+B`）** — 書き出さずに既定の
  ブラウザで開きます。**画面では図にならない Mermaid・数式・コードの色が
  ここで見られます。** 一時ファイルへ書くので、保管フォルダは汚れません
- **「ファイル」→「HTML をコピー」** — 書式付きでコピーします。メールや
  チャットにそのまま貼れます。画像も一緒に入ります

## 覚えておくと安心なこと

- **保存は自動です。** 入力が止まって 0.8 秒後、ノートを切り替えたとき、
  アプリを閉じたときに書き込まれます。まだ書けていない間は
  ウィンドウのタイトルに `•` が付き、**書けたら右下に保存した時刻**が出ます
  （打ち始めると消えます）
- **今入っているモード**（Raw / フォーカス / タイプライタ）が右下に出ます。
  何も入っていなければ何も出ません。ツールバーを隠していると（`Cmd+3`）
  Raw かどうかはここでしか分かりません
- **文字数と行数**が右下に出ます。装飾の記号（`**` など）と front matter、
  改行そのものは数に入りません
- **次に開くと、前回書いていたノートがそのまま開きます**
- **`Cmd+[` で来た道を戻れます。** 押した回数だけ前のノートへ遡ります
- **外部エディタと併用できます。** 別のアプリで書き換えると自動で読み直します。
  両方で同時に編集した場合は、どちらを残すか尋ねます
- **消えたファイルは `.trash` にあります。** 30 日で自動削除されます
  （日数は環境設定で変えられます）。左の「ゴミ箱」を開き、一覧を右クリックして
  **「元に戻す」**で戻せます
- **今すぐ消すこともできます。** ゴミ箱の一覧を右クリックして
  **「完全に削除…」**（1 件）、左の「ゴミ箱」を右クリックして
  **「ゴミ箱を空にする…」**（全部）。どちらも件数か名前を見せて確認します。
  **戻せません**
- **ピン留めしたノートは一覧に黄色い星が付き**、どの並び順でも先頭に出ます。
  左の「お気に入り」にも集まります
- **フォルダで絞っている間の新規ノートは、そのフォルダの中にできます**
  （テンプレートから新規も同じ）。日報フォルダを選んで書き始めれば、
  毎日のノートがそこに揃います。「今日のノート」（Cmd+T）だけは
  今まで通り保管フォルダ直下です
- **左の「フォルダ」を右クリック →「新しいフォルダ…」で作れます。** 選んだ
  フォルダの中にできます（「直下」から作れば保管フォルダの直下）。
  **空のフォルダもそのまま並びます**ので、先に箱を作ってから入れる順序でも
  使えます。**ノートを移したり捨てたりしてフォルダが空になっても、
  フォルダは残ります**（勝手に消えません）
- **フォルダを消すときは**同じ右クリックの「フォルダを削除…」です。
  中にノートが残っているときは消しません（先にノートを移すか捨てて
  ください）
- **一覧の右クリック →「フォルダへ移動…」でノートを移せます。** 移動先に
  新しい名前を打てば、そのフォルダがその場で作られます。移動で空になった
  フォルダは自動で片づきます。本文はそのままなので、画像も壊れません
- **フォルダで分けることもできます。** Finder で保管フォルダの中にフォルダを
  作り、`.md` を入れてください。そのまま一覧にも検索にも出ます。
  **名前の変更や複製をしても、そのフォルダに留まります**
- **よく使う検索は保存できます。** メニューの「検索 → 検索を保存…」で
  `#仕事 after:2026-08-01` のような式に名前を付けると、左の「検索」に
  並びます。選ぶと当てはまるノートだけが一覧に出ます。フォルダと違って
  **ノートを動かさずに束ねられ**、1 つのノートが複数の束に入れます。
  消すときはサイドバーで右クリックしてください
- **フォルダは左の「フォルダ」に並びます。** 選ぶとその中のノートだけになります
  （中のフォルダのぶんも入ります）。先頭の**「直下」はフォルダに入れていない
  ノートだけ**です（こちらは中のフォルダを含みません。「すべて」と同じ意味に
  なってしまうため）。フォルダが 1 つも無くても「直下」は出ます。「すべて」のときは、一覧の行の右に
  `仕事` のように置き場所が小さく出ます（保管フォルダの直下なら出ません）
- **ノートの名前は本文の見出しです。** 「名前を変更」は見出しを書き換えます。
  ファイル名もそれに合わせて変わります
- **ピン留めしたノートは削除できません。** 消したいときは先にピン留めを外してください
- **前の状態に戻せます。**「ファイル」→「版の履歴…」（`Cmd+Shift+H`）で、
  保存してきた内容が新しい順に並びます。中身を見てから「この版に戻す」を
  押してください。**戻す前の内容も 1 版として残る**ので、戻したあとで
  やっぱり元に戻すこともできます
- **版は 5 分おきに 1 つ**残ります（打つたびに増えることはありません）。
  1 ノートにつき 50 版まで、30 日で消えます
- **検索用のデータは消しても平気です。** `.hitofude` フォルダを削除しても、
  `.md` から作り直されます。**ただし版の履歴も `.hitofude` の中にあります。**
  こちらは作り直せないので、消すと前の状態には戻せなくなります
- **文字の大きさは `Cmd+＋` と `Cmd+ー` で変えられます**（`Cmd+0` で標準に戻ります）。
  変えた大きさは覚えていて、次に開いたときも同じです。環境設定の「文字サイズ」と
  同じものを触っています
- **一覧とサイドバーの行間は環境設定の「行間」で変えられます**（詰めて / ふつう /
  ゆったり）。本文には効きません。「ゆったり」は 1 画面に入るノートが減ります
- **タブ幅は環境設定で変えられます**（既定は 4 文字）。見せ方が変わるだけで、
  書いた文字は変わりません
- **保管フォルダは打ち込んでも変えられます**（`~/` で書けます）。「変更…」から
  選ぶこともできます。使えない場所（ファイル・相対パス・親の無い場所）は受け取りません
- **環境設定は「デフォルトに戻す」で元に戻せます。** 保管フォルダはそのままです
- **このノートは「ヘルプ」メニューから置き直せます。** アプリが新しくなって
  説明が増えたときは、そこから最新版を出してください（今あるノートは消えません）
