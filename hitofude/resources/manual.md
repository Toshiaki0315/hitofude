# Hitofude の使い方

ようこそ。このノート自体が Markdown で書かれているので、**書き方の見本**にもなります。
不要になったら `Cmd+Delete` でゴミ箱へ入れてください。

## このアプリの考え方

編集画面とプレビュー画面が分かれていません。書きながら装飾が反映されます。

記号（`**` や `#`）は**カーソルがその要素の外にあるとき隠れます**。中に入れると
現れて、そのまま直せます。この行の *斜体* や `コード` にカーソルを合わせてみてください。

ノートは**素の `.md` ファイル**として保存されます。独自形式は使いません。
`~/Documents/HitofudeNotes` を Finder で開けば、そのまま他のアプリでも読めます。

## 書き方

本文の上のボタンからも付けられます（次の節）。

### 文字の装飾

これは **強調**、これは *斜体*、これは ~~取り消し線~~、これは ::ハイライト::、
そしてこれは `インラインコード` です。

日本語でも**前後に空白を入れずに**装飾できます。「**強調**」のように括弧に
隣接しても効きます。

### 箇条書きとタスク

- 項目を書いて Enter を押すと、次の行にも `- ` が付きます
- Tab で字下げ、Shift+Tab で戻せます
    - 入れ子にした項目
- 空の項目で Enter を 2 回押すと、ふつうの段落に戻ります

1. 番号付きの箇条書き
2. 番号は自動で 1 つ進みます
3. 途中の番号は振り直しません（差分を小さく保つため）

- [ ] まだ終わっていない項目
- [x] 終わった項目

### 引用とコード

> 引用は左に縦線が付きます。
> 行末で Enter を押すと引用が続きます。

```python
def hello() -> str:
    """コードブロックの中では装飾が一切効きません。"""
    return "**これは強調になりません**"
```

### 表

表は縦線を揃えると読みやすくなります。行から離れると**自動で揃い、罫線が付きます**。
手で揃えたいときは `Cmd+Shift+L` を押してください。

| 記法   | 書き方       | 結果     |
| ------ | ------------ | -------- |
| 強調   | `**文字**`   | **文字** |
| 斜体   | `*文字*`     | *文字*   |
| コード | `` `文字` `` | `文字`   |

表の中にカーソルを入れると罫線が消えて `|` が現れます。そのまま編集できます。

### 画像

**画像はそのまま貼り付けられます。** スクリーンショットを撮って `Cmd+V`、
または画像ファイルをウィンドウへドラッグしてください。`attachments/` に
保存され、本文には `![](attachments/…)` が入ります。

**その場に絵が出ます。** カーソルを入れても絵は消えず、行の高さも変わりません。
パスを直したいときは `Cmd+/` で生の Markdown に戻せます。

大きい画像は本文の幅に収めて表示します（元のファイルは縮みません）。

### リンク

[Markdown の仕様](https://spec.commonmark.org/) のように書きます。
`Cmd+K` で選択した文字をリンクにできます。URL をコピーした状態で文字を選んで
`Cmd+V` すると、リンクとして貼り付きます。

### タグ

本文のどこにでも `#タグ` と書けます。`/` で階層にできます。
左のサイドバーにツリーとして出ます。

`#` の**直前は行頭か空白**である必要があります。URL の `#anchor` を
タグと誤認しないためです。

### Qiita 向けの書き方

Qiita に貼るときの記法にも対応しています。まず囲みです。

:::note info
これが `:::note info` の囲みです。**強調**も箇条書きも中で使えます。
:::

:::note warn
`warn` は黄色。注意を促すとき。
:::

:::note alert
`alert` は赤。危険なとき。
:::

書き方はこうです。種類を省くと `info` になります。

    :::note info
    お知らせです。
    :::

`:::` の行は画面では消えていて、**カーソルを入れると現れます**。
囲みであることは左の色付きの縦線で分かります。

**綴りを間違えると灰色の線になり、`:::note warm` の行も消えません。**
`info` の青で出してしまうと、間違えたことに気づけないためです。
`:::note warn さらに何か` のように語を 2 つ以上書いた場合は、囲みになりません。

コードブロックには**ファイル名**を付けられます。画面ではコードの上に、
書き出しでは見出しとして出ます。

```js:index.js
const greeting = "書き出すとファイル名が見出しとして出ます";
```

**脚注**も書けます[^1]。書き出すと本文のいちばん下にまとまります。

[^1]: これが脚注の中身です。`[^1]: ` で始まる行が定義になります。

**これらは Markdown の標準ではありません。** 他のアプリで開くとそのままの
文字に見えますが、書いた内容は何も失われません。

## 書式ツールバー

本文の上に並んでいるボタンで、太字・斜体・打ち消し・コード・マーカー・
見出し・箇条書き・番号付き・チェックボックス・引用・リンクを付けられます。
ショートカットを覚えていなくても押せます。

- **囲む系（太字など）は、先に文字を選んでから押します。** 選ばずに押すと
  記号だけが置かれ、その間にカーソルが入ります
- **行の書式（箇条書き・番号付き・引用）は、選んだ行すべてに効きます。**
  行の途中までしか選んでいなくても、その行は丸ごと対象です
- もう一度押すと外れます。`Cmd+Z` は 1 回で元に戻ります
- 「見出し」は押すたびに 段落 → 大見出し → 中見出し → 小見出し → 段落 と
  一周します。もっと深い見出しは `Cmd+Shift+↓` で付けられます
- 邪魔なときは `Cmd+3` で隠せます。次に開いたときも隠れたままです

## 書き出し

「ファイル」メニューから 3 つの形式で書き出せます。書き出しても**元のノートは
変わりません**。

| 形式     | キー          | 中身                                       |
| -------- | ------------- | ------------------------------------------ |
| Markdown | `Cmd+Shift+M` | 書いたそのまま。記号も残ります             |
| HTML     | `Cmd+Shift+E` | 1 ファイルで完結。**画像も埋め込まれます** |
| PDF      | `Cmd+P`       | A4。表の罫線とコードの背景も付きます       |

- HTML と PDF には**チェックボックス（☐ / ☑）・`:::note` の囲み・
  コードのファイル名・脚注**もそのまま出ます
- HTML は画像を中に取り込むので、**別の場所へ移しても絵が消えません**
- どの形式でも front matter（`id` や `modified`）は出ません。アプリの
  管理情報で、読む人には意味がないためです
- PDF だけは**引用の縦線が出ません**（PDF の描画側の制限です）。
  HTML には出ます

## 覚えておくと安心なこと

- **保存は自動です。** 入力が止まって 0.8 秒後、ノートを切り替えたとき、
  アプリを閉じたときに書き込まれます。まだ書けていない間は
  ウィンドウのタイトルに `•` が付きます
- **文字数と行数**が右下に出ます。装飾の記号（`**` など）と front matter、
  改行そのものは数に入りません
- **次に開くと、前回書いていたノートがそのまま開きます**
- **外部エディタと併用できます。** 別のアプリで書き換えると自動で読み直します。
  両方で同時に編集した場合は、どちらを残すか尋ねます
- **消えたファイルは `.trash` にあります。** 30 日で自動削除されます
  （日数は環境設定で変えられます）。左の「ゴミ箱」を開き、一覧を右クリックして
  **「元に戻す」**で戻せます
- **一覧の右クリック**からピン留め・名前の変更・ゴミ箱への移動ができます。
  ピン留めしたノートは一覧に**黄色い星**が付き、左の「お気に入り」に集まります
- **ノートの名前は本文の見出しです。** 「名前を変更」は見出しを書き換えます。
  ファイル名もそれに合わせて変わります
- **ピン留めしたノートは削除できません。** 消したいときは先にピン留めを外してください
- **検索用のデータは消しても平気です。** `.hitofude` フォルダを削除しても、
  `.md` から作り直されます
- **環境設定は「デフォルトに戻す」で元に戻せます。** 保管フォルダはそのままです
- **このノートは「ヘルプ」メニューから置き直せます。** アプリが新しくなって
  説明が増えたときは、そこから最新版を出してください（今あるノートは消えません）
