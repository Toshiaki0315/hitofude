# ADR-0009: 数式は MathML にする。PDF だけ LaTeX のまま出す

- **日付**: 2026-08-10
- **状態**: 採用
- **覆す対象**: なし。TASKS.md B-5 の「MathJax（`tex-svg`）の同梱で足りる」
  という見積もりを**置き換える**。ADR-0007 の「HTML と PDF は同じ文字列を
  使う」に**唯一の例外**を作る

## 背景

`$...$` / `$$...$$` を数式として組みたい（TASKS.md B-5）。数式の組版は
KaTeX も MathJax も JavaScript 実装で、Python には無い、というのが出発点
だった。

## 決定

**`latex2mathml` で MathML にする。** JavaScript は同梱しない。

**PDF だけは LaTeX のまま出す。** Qt のリッチテキストは MathML を解さない。

**画面では組版しない。** インライン数式を等幅で見せて「式として書いた」と
分かるところまでにする。

## 根拠

**候補を 3 つ測った。**

| 案 | サイズ | HTML | PDF | 画面 |
|---|---|---|---|---|
| MathJax（`tex-svg`）を同梱 | 書き出し 1 ファイルごとに +1MB 以上 | ◎ | × | × |
| **`latex2mathml`** | **352KB**（純 Python、変換 0.3ms） | ◎ | × | × |
| matplotlib で画像にする | **74MB** | ○ | ○ | ○ |

matplotlib だけが 3 つとも satisfy するが、**数式ひとつのために 74MB** は
釣り合わない。MathJax は「外部リソースを参照しない」を守るなら同梱するしか
なく、書き出したファイルが毎回 1MB 太る。MathML は今のブラウザ（Chrome /
Safari / Firefox）がそのまま組む。

**PDF について。** MathML をそのまま `setHtml()` に渡すと、Qt はタグを捨てて
中身の文字を繋ぐ。**黙って間違った式**になる（実測）。

| 書いたもの | Qt が出すもの |
|---|---|
| `$E = mc^2$` | `E=mc2` |
| `$$\frac{a}{b}$$` | `ab` |

`ab` は分数ですらない。**間違った式を自信ありげに出すくらいなら、書いた
ままの LaTeX を見せるほうがよい。** 読む人は「これは数式だ」と分かるし、
中身も正しい。

## 誤検出をどう抑えたか

`$` は日本語の文章にも出てくる（値段）。ここが緩いと**ふつうの文章が壊れる**。

1. `allow_space=False` … `$ x $` を数式にしない
2. `allow_digits=False` … `100$` のように数字が隣接するものを数式にしない
3. **かな・漢字を含むものを数式にしない**（自前）

3 はブラウザで実物を見て見つけた。1 と 2 だけでは、

    価格は $100 と $200 です。定価 100$ から $200 まで。

の**1 つ目の閉じと 2 つ目の開きが組**になり、`200です。定価100` が数式として
組まれていた。テストは短い行で書いていたので素通りしていた。数式に かな・漢字
は出てこないので、含むものは取り違えと見なす。

## 影響

- 依存が 1 つ増えた（`latex2mathml` 352KB）
- **ADR-0007 の「HTML と PDF は同じ文字列」に例外ができた。** 例外はここだけで、
  `core/html.render(math_as_source=True)` という 1 つの旗で表す
- 画面では**式だと分かるところまで**を出す。行内の `$...$` と `$$...$$` は
  等幅にし、複数行の `$$` ブロックはコードブロックと同じ背景で表す
  （`$$` の行は潰す）。LaTeX が見えていること自体は、ソースを編集する
  道具として妥当と判断した
- **1 行に書いた `$$x$$` を最初は画面で拾えていなかった**（書き出しでは数式に
  なるのに画面では素通り）。ユーザーが実機で試して見つけた。行内の走査で
  `$$` を `$` より先に見るようにした（あとにすると `$$a$$` が `$` と `$a$` に
  割れて範囲がずれる）
- 画面で組版したくなったら matplotlib（74MB）を積む判断が要る。そのときは
  ADR-0004 の仕組み（行高を文字サイズで作る＋キャッシュ）にそのまま乗る
