# ADR-0010: タグの絞り込みは `Cmd+クリック` にする

- **日付**: 2026-08-14
- **状態**: 採用
- **覆す対象**: spec.md §5.2 の表「タグ `#tag`: 背景色付きピル形状。**クリック**で
  そのタグで絞り込み」

## 背景

仕様書はリンクを `Cmd+クリック`、タグを**素のクリック**と書き分けていた。
D-1 / D-2 で実装するにあたり、この差が実際に成立するかを検討した。

## 決定

**どちらも `Cmd+クリック` にする。**

## 根拠

**素のクリックはキャレットの移動である。** エディタの中では、押した場所に
キャレットが立つことが最優先の意味を持つ。タグの上を押しただけで一覧が
絞り込まれると、

- タグの綴りを直そうとして押すたびに、一覧が別のものに切り替わる
- 選択範囲を作ろうとしてタグを跨いだだけで発火する

という取り合いが起きる。**書く道具としての基本操作を、副作用のある操作に
明け渡すことになる。**

`Cmd+` を要る形にすると、リンクと同じ約束になり、覚えることも 1 つで済む。

## 影響

- 仕様書 §5.2 の表と食い違う。仕様書側にこの ADR への参照を書いた
- タグの見た目（背景色付きピル）は変えていない。押せることが分かりにくい
  面はあるが、`Cmd+` を要る操作は他にもある（リンク）ので揃えた
