# ADR（Architecture Decision Record）

**仕様書 [../spec.md](../spec.md) の決定を覆すときだけ**、ここに記録を残す。

spec.md は実機検証に基づいた設計判断の集合であり、原則として真実はそちら側にある。
実装を進める中で「仕様書のほうが間違っている」と判断した場合は、

1. 実装する前に理由を述べて確認を取る
2. `NNNN-<短いスラッグ>.md` を追加する
3. spec.md の該当節に「→ ADR-NNNN で変更」と追記する

の順で進める。

## テンプレート

```markdown
# ADR-0001: <決定の要約>

- **日付**: YYYY-MM-DD
- **状態**: 提案 / 採用 / 破棄 / ADR-NNNN で置換
- **覆す対象**: spec.md §X.Y

## 背景
何が起きて、なぜ仕様書どおりでは進めないのか。

## 決定
何をどう変えるか。

## 根拠
実測値・テスト結果・引用。憶測は書かない。

## 影響
どのモジュール・タスク・不可侵ルール（CLAUDE.md §3）に波及するか。
```
