# ADR-0018: 本文の横幅を設定で変えられるようにする

日付: 2026-08-19
状態: 採用（spec §5.1 の「最大 720px」を既定値に格下げ）

## 文脈

spec §5.1 は読みやすさのため本文を中央寄せ・最大 720px と固定していた。
ユーザーから「横幅を設定で変更できるか」の問いがあり（TASKS これから I-3）、
検討の結果、固定をやめて選択式にする。

## 決定

- 行間（`LineSpacing`）と同じ**「名前から値」方式**。設定には px ではなく
  名前（`standard` / `wide` / `full`）を保存し、px は対応表
  （`config.CONTENT_WIDTH_PIXELS`）が決める
- 選択肢は **標準 720**（spec §5.1 の既定・不変）/ **広め 880** /
  **最大（ウィンドウ幅いっぱい）= 0**
- 適用は `MarkdownEditor.set_content_width(px)` の一点。余白（中央寄せ）・
  表の桁数・画像の最大幅はすべて幅から導出されているので、そこから
  まとめて更新する
- 「最大」ではウィンドウのリサイズに合わせて画像の予約高さも変わるため、
  画像の行だけ `rehighlightBlock` する（全体再ハイライトはしない。R7）

## 影響

- 表の「1 行 69 桁」は標準幅のときの値になる。広めなら約 90 桁、最大なら
  ウィンドウ幅に応じて変わる。折り返し表（ADR-0017）の列幅も連動する
- 設定画面（Cmd+,）に「本文の幅」のコンボが増える。既定は標準なので、
  何もしなければ今までと同じ
