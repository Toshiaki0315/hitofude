# 手動テストチェックリスト

自動化できない、または自動化しても意味が薄い項目（spec §10）。
リリース前と、Phase をまたぐ変更のあとに通す。

自動テストで担保済みの項目はここに書かない。**ここにあるのは
「機械では確かめられない」ものだけ**。

## 1. 日本語入力（IME）

仕様書 §11 R2 が「怠ると日本語入力が壊滅的に使えなくなる」と名指ししている領域。
`QTest.keyClicks` は ASCII しか送れないため、**打鍵レベルの日本語入力は
自動テストで再現できない**（CLAUDE.md §1 に記載）。

| | 確認すること | 期待 |
|---|---|---|
| [ ] | 「にほんご」と入力し変換候補を出す | 候補が消えたりちらついたりしない |
| [ ] | 変換候補が出ている状態で数秒待つ | 候補が勝手に閉じない |
| [ ] | 変換を確定する | 確定した文字だけが入り、余計な改行が入らない |
| [ ] | `- ` の行で「こうもく」と入力し変換確定 | **リストが増えない**（R6） |
| [ ] | 上の状態からさらに Enter | ここで初めて次の `- ` が出る |
| [ ] | 変換中に Tab を押す | 字下げが発火しない |
| [ ] | 変換中に `Cmd+B` を押す | 太字化が発火しない |
| [ ] | `Cmd+F` の検索欄で日本語を変換し Enter で確定 | **確定するだけ。本文へカーソルが飛ばない** |
| [ ] | 「きょうちょう」を変換確定し、選択して `Cmd+B` | `**強調**` になり装飾される |
| [ ] | 変換確定と同時に装飾が反映されるか | 確定した瞬間に太字になる |
| [ ] | 長文（500 字以上）を変換しながら入力 | 引っかかりを感じない |
| [ ] | ライブ変換（macOS の設定）を有効にして入力 | 候補が壊れない |

## 3. 外部エディタとの併用

ファイルシステムのイベントは環境差が大きく、自動テストでは
タイミングを再現しきれない。

| | 確認すること | 期待 |
|---|---|---|
| [ ] | アプリで開いていないノートを外部エディタで書き換える | 一覧のプレビューが更新される |
| [ ] | 開いているノートを外部で書き換える（アプリ側は未編集） | 静かに再読み込みされる |
| [ ] | 開いているノートを外部で書き換える（アプリ側も編集中） | 競合ダイアログが出る |
| [ ] | 競合ダイアログで「両方残す」 | `名前 (競合 日付).md` ができ、内容が両方残る |
| [ ] | 開いているノートを外部で削除する | 作り直すか尋ねられる |
| [ ] | Finder でノートをリネームする | 一覧に反映される |
| [ ] | vault にサブフォルダを作り `.md` を置く | 一覧に出る |
| [ ] | アプリで編集して保存する | **外部変更として通知が来ない**（自己書き込みの抑制） |
| [ ] | iCloud Drive 配下に vault を置いて使う | 保存・再読み込みが破綻しない |
